# Decision records

Each page here records one decision: what was decided, when, why, and what it cost. The full
reasoning is in the
[design specification](https://github.com/EmadMokhtar/agents-skills/tree/main/docs/superpowers/specs).

An accepted record is history, so it is never edited. To change a decision, write a new
record and mark the old one *Superseded*.

To add one, copy `template.md`, take the next number, and add it to the nav in `mkdocs.yml`.
