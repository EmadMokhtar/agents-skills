# Security policy

## Report a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead. Open the **Security** tab of this
repository, choose **Report a vulnerability**, and describe the problem and how to reproduce it.

We will acknowledge your report and keep you informed until the problem is fixed.

## What counts

Anything that lets someone read or change data they should not, run code they should not, or
learn a secret. A secret that was committed by mistake counts too: report it, and do not rely
on deleting the commit, because the value is already exposed.
