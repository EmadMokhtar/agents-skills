# Decision records

Each page here records one decision: what was decided, when, why, and what it cost. They are
short on purpose.

An accepted record is history, so it is never edited. To change a decision, write a new record
and mark the old one *Superseded*. For the same reason, these pages are not checked for
staleness.

To add one, copy `template.md`, take the next number, and add it to the table
below.
