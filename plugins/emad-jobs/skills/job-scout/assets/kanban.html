How this works

This board reads and writes the jobs.json file in your job search folder — the same file the job-scout agent keeps up to date. Click Open jobs.json once per session and grant access. To change a card's status, either click the ⋯ button on the card and pick a column, or drag the card across. Either way the change saves back to jobs.json automatically (a backup is also kept in this browser). When a card moves to Applied, today's date is recorded. The agent reads this file, skips anything already here (matched by URL, job id, or company and title), and adds only new roles — so a job is never added twice. Moves you make here are recorded as yours, and the agent never changes a status you set or your notes.

Spotting stale applications: every card shows its age. In Applied and In Process the clock runs from the date you applied, and the age turns amber after 14 days of silence and red after 30 — those two columns also sort longest-wait-first and show a "N stale" badge in the header. Elsewhere the age is grey and runs from when the role was found, since nothing is pending. Hover any age for the exact date.

Keeping the board manageable: each column scrolls on its own and the board always fits one screen, so a long column no longer stretches the page. Click any column header to collapse it into a slim strip — Archived starts collapsed, and your choice is remembered. A collapsed column still accepts dropped cards. While dragging, moving the pointer near an edge scrolls automatically.

Note: direct file save uses Chrome/Edge's File System Access API. In other browsers, use Save to download an updated jobs.json and drop it back into the folder.
